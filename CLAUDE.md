# DTP AI Authoring Tools – Project Instructions

## 1. Project Overview

This project aims to develop an AI-powered educational content authoring system for DTP.

The system transforms existing educational materials uploaded by users into structured interactive learning content.

Primary users:
- Teachers
- Educational content developers
- Academic administrators

## 2. Core Product Objectives

The system should support:

1. Uploading PDF and educational documents.
2. Extracting text, images and learning materials.
3. Identifying learning objectives.
4. Generating interactive questions and activities using AI.
5. Supporting reusable learning activity templates.
6. Exporting HTML5 and SCORM packages.
7. Integrating with DTP's LCMS platform.

## 3. Technology Principles

- Python for AI processing and backend prototypes.
- HTML5, CSS and JavaScript for interactive learning content.
- JSON for structured educational content.
- SCORM for LMS interoperability.
- Modular architecture for future expansion.

Do not assume that a technology has already been implemented unless confirmed in the source code.

## 4. Development Rules

- Keep code modular and readable.
- Use meaningful function and variable names.
- Validate all user inputs.
- Handle errors explicitly.
- Avoid unnecessary dependencies.
- Do not modify unrelated files.
- Explain important changes before implementation.
- Add tests for important business logic.

## 5. Educational Content Quality

Generated content must:

- Preserve the meaning of the original educational material.
- Match the intended learner age and proficiency level.
- Use clear and appropriate language.
- Have unambiguous correct answers.
- Provide meaningful feedback.
- Distinguish between source information and AI-generated suggestions.

## 6. AI Development Rules

- Analyze before modifying files.
- Explain the proposed implementation.
- Ask for approval before destructive operations.
- Never expose API keys, passwords or credentials.
- Do not claim that code has been tested unless tests were actually executed.

## 7. Communication

Explain technical concepts in clear language.

When introducing new technical terminology:
- Give the English term.
- Explain its meaning in Vietnamese.
- Provide a practical example.

The project owner has a background in finance, operations and educational publishing. Technical explanations should connect software concepts to real EdTech business processes.
